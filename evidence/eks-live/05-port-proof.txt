=== PROOF by failure mode: dropped (timeout) vs refused (instant RST) ===
If the node SG drops the packet  -> TIMEOUT (~3s, no response)
If the SG allows but nothing listens -> REFUSED (instant, RST)

Self-rule covers tcp 1025-65535. Port 80 is outside it; port 8080 is inside it.
Nothing listens on 8080 on any web pod - so 8080 must be REFUSED if the SG allows it.
